# LuxLogoGovDocs

> Government Docs site logo.

## Props

| Prop name | Description             | Type           | Values | Default |
| --------- | ----------------------- | -------------- | ------ | ------- |
| width     | The width of the logo.  | number\|string | -      | 32      |
| height    | The height of the logo. | number\|string | -      | 32      |

```jsx
<div>
  <lux-logo-gov-docs></lux-logo-gov-docs>
</div>
```
