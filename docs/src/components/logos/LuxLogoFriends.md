# LuxLogoFriends

> Official logo for Friends of PUL.

## Props

| Prop name | Description             | Type           | Values | Default |
| --------- | ----------------------- | -------------- | ------ | ------- |
| width     | The width of the logo.  | number\|string | -      | 115     |
| height    | The height of the logo. | number\|string | -      | 31      |

<div>
