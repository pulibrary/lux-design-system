# LuxLogoFriends

## Props

| Prop Name | Description | Type | Default |
| :--- | :--- | :--- | :--- |
| `width` | The width of the logo. | `[Number, String]` | `115` |
| `height` | The height of the logo. | `[Number, String]` | `31` |

## Usage

```jsx
  <div>
    <lux-logo-friends></lux-logo-friends>
  </div>
  ```
