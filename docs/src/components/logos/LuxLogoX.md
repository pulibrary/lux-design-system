# LuxLogoX

> X logo for social media sharing purposes.

## Props

| Prop name | Description             | Type           | Values | Default |
| --------- | ----------------------- | -------------- | ------ | ------- |
| width     | The width of the logo.  | number\|string | -      | 24      |
| height    | The height of the logo. | number\|string | -      | 24      |

---

```jsx
<div>
  <lux-logo-x></lux-logo-x>
</div>
```
