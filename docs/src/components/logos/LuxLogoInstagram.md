# LuxLogoInstagram

## Props

| Prop Name | Description | Type | Default |
| :--- | :--- | :--- | :--- |
| `width` | The width of the logo. | `[Number, String]` | `24` |
| `height` | The height of the logo. | `[Number, String]` | `24` |

## Usage

```jsx
  <div>
    <lux-logo-instagram></lux-logo-instagram>
  </div>
  ```
