# LuxLogoUniversity

> Official Princeton University Logo

## Props

| Prop name | Description             | Type           | Values | Default |
| --------- | ----------------------- | -------------- | ------ | ------- |
| width     | The width of the logo.  | number\|string | -      | 263     |
| height    | The height of the logo. | number\|string | -      | 72      |

<div>
