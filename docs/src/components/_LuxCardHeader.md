# _LuxCardHeader

## Props

| Prop Name | Description | Type | Default |
| :--- | :--- | :--- | :--- |
| `type` | The html element name used for the wrapper. | `String` | `"div"` |

## Usage

```jsx
  <div>
    <lux-card-header>
      <lux-heading level="h2" size="h3">Title</lux-heading>
      <lux-text-style>Secondary title</lux-text-style>
    </lux-card-header>
  </div>
  ```
